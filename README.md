# EcoTrack
O EcoTrack é uma aplicação que conecta cidadãos e gestão pública para identificar e resolver problemas urbanos relacionados aos quatro eixos do saneamento básico: abastecimento de água, esgotamento sanitário, manejo de resíduos sólidos e drenagem urbana. Por meio da tecnologia, o projeto busca promover cidades mais limpas e sustentáveis.
